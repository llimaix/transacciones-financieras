## RNF-01 Consistencia (crítico)
- El sistema debe garantizar que las operaciones sean coherentes: sin pérdida ni creación indebida de dinero.
- _(Ampliar: atomicidad, rollback en caso de falla, etc.)_

## RNF-02 Confiabilidad
- El sistema debe manejar correctamente escenarios de error.
- _(Ampliar: tiempos de recuperación, notificaciones de falla, etc.)_

## RNF-03 Mantenibilidad
- El diseño debe permitir cambios en reglas de negocio sin afectar el sistema completo.
- _(Ampliar: qué decisiones de diseño lo hacen mantenible)_

## RNF-04 Seguridad (conceptual)
- El sistema debe contemplar validaciones que eviten operaciones inválidas.
- _(Ampliar: autenticación, autorización, límites de operación, etc.)_
