CP-02Alterno

Fondos insuficientes

CU-02 / CU-03 · RF-04
Historia

El operador intenta transferir Q500.00 desde CTA-10001, pero esa cuenta solo tiene Q100.00. El sistema debe detenerse antes de mover dinero y explicar el motivo, sin alterar saldos.

Validación
  1. Ingresar datos y confirmar.
  2. Validar fondos: saldo < monto.
  3. Rechazar y registrar RECHAZADA.
Resultado: operación rechazada, saldos sin cambios, transacción RECHAZADA con motivo "Fondos insuficientes".

CP-04Error

Transferencia duplicada

CU-02 / CU-03 · RF-05
Historia

Por un reintento (doble clic o reenvío de red) llega otra vez una transferencia con la misma referencia única (REF-000457) de una operación ya ejecutada. El sistema no debe mover el dinero de nuevo: reconoce el duplicado y devuelve el resultado original. Es la garantía de idempotencia.

Validación
  1. Reenviar solicitud con referencia ya procesada.
  2. Detectar la referencia repetida.
  3. Devolver el resultado original sin re-ejecutar.
Resultado: sin segundo movimiento, se devuelve el resultado original, mensaje "Operación duplicada detectada", saldos sin cambios.
